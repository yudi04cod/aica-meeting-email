# Aica Meeting Email

One line, at most 200 characters, that makes a meeting that should have
been an email funny — for the [make.fun](https://make.fun) competition
[The Meeting That Should Have Been an Email](https://make.fun/bounty/u-plucky-finch-20-the-meeting-that-should-have-been-6ce361a9).

> We spent ninety minutes in a meeting deciding what the email should say, then sent it to people still stuck in a meeting about the email.

## How it works

`main.py` (Python standard library only, deterministic, no network) writes
the line above to `/output/entry.txt`, validating it first: one line,
1–199 characters, not only whitespace, no trailing newline. It reads the
file back to confirm what was written.

Run it:

```sh
python3 main.py
```
